# LR0_intellect_sysstem

Лабораторная работа №0.
Интеллектуальные системы.

## Описание

Исследование воспроизводимости обучения нейронных сетей
и подбор гиперпараметров с использованием PyTorch,
Optuna и MLflow.

## Структура

- configs/ — конфигурации экспериментов
- data/ — данные и разбиение
- src/ — исходный код
- reports/ — отчёты и графики
- runs/ — результаты запусков
